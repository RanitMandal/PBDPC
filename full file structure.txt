### সবচেয়ে গুরুত্বপূর্ণ path

যেহেতু `index.html` root-এ:

```text
PBDPC/index.html
```

তাই CSS হবে:

```html
<link rel="stylesheet" href="assets/css/style.css">
```

JS হবে:

```html
<script src="assets/js/config.js"></script>
<script src="assets/js/components.js"></script>
<script src="assets/js/app.js"></script>
```

Logo:

```html
<img src="assets/images/logo.png" alt="PBDPC Logo">
```

Hero:

```html
<img src="assets/images/home/hero1.jpg" alt="Protappur Baroari Durga Puja Temple">
```

Header component:

```html
<div id="header"></div>
```

Footer component:

```html
<div id="footer"></div>
```

### আর একটা গুরুত্বপূর্ণ বিষয়

**সব HTML page root-এই থাকবে।**

অর্থাৎ:

```text
PBDPC/
├── index.html
├── about.html
├── history.html
├── temple.html
├── gallery.html
├── committee.html
├── events.html
├── sponsors.html
├── donation.html
└── contact.html
```

`assets/`-এর ভিতরে কোনো HTML page রাখব না।

এতে navigation খুব simple হবে:

```html
<a href="index.html">Home</a>
<a href="about.html">About</a>
<a href="history.html">History</a>
<a href="temple.html">Temple</a>
<a href="gallery.html">Gallery</a>
<a href="committee.html">Committee</a>
<a href="events.html">Events</a>
<a href="sponsors.html">Sponsors</a>
<a href="donation.html">Donate</a>
<a href="contact.html">Contact</a>
```

এটাই আমাদের **final project structure** হিসেবে ধরে পরের code তৈরি করা উচিত।
